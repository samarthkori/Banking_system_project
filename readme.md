## 💻 How to View & Run This Project Locally

Follow these instructions to run this project on your computer:

### 1. Prerequisites

Make sure you have Python installed on your system. You can verify it by opening your terminal/command prompt and running:

```
python --version

```

### 2. Get the Code

You can clone this repository using Git:

```
git clone https://github.com/samarthkori/Banking_system_project.git

```

*(Or click the green **Code** button at the top of GitHub and select **Download ZIP**, then extract it).*

### 3. Open the Project

Navigate into the folder:

```
cd Banking_system_project

```

### 4. Run the Application

Run the main script:

```
python main.py

```
